A — Inline edit (recommended)

Click the pencil on any row to edit it in place. One field at a time. Simple — matches how the existing API works (PUT /business-rules/{chave}).

B — Edit-all modal

One "Editar" button opens a modal with all fields. Save fires multiple API calls. Simpler UX but loses per-field audit trail — can't record a different motivo per field.
